2026-10-14 배포 준비: API 업데이트 버전을 v2.70(versionCode 145)로 확정했습니다. 기존 v2.62(144) 배포판과 구분하며 145 AAB 빌드 검증·Play Console 출시는 별도로 확인합니다.
