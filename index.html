StarTrade(스타매매)
개인정보처리방침

  • 시행일: 2026년 10월 12일
  • 운영자: LOWSKY Lab (Google Play 개발자명: dodae)
  • 개인정보 문의: lowsky.lab@gmail.com

StarTrade(스타매매)는 회원가입이나 개발자 서버를 운영하지 않으며, 운용자료는 원칙적으로 사용자의 기기 안에서 처리합니다. 외부 종가·환율 조회와 사용자가 직접 선택한 Google Drive 백업에 한해 아래와 같이 외부 서비스와 통신합니다.

1. 처리하는 정보와 목적

구분처리 항목목적
운용자료 종목코드·종목명, 운용조건, 체결일·매매구분·가격·수량·수수료·세금, 종가, 일별 환율·기준일·제공처, 손익, 앱 설정 운용 계산·기록, 주문계획 작성, 통계와 백업·복원
외부 종가·환율 종목코드 또는 통화쌍·조회 기간, 요청 과정에서 서비스 제공자에게 전달되는 IP 주소 등 통신정보 Yahoo Finance 또는 Twelve Data를 통한 종가·환율 조회
Twelve Data 인증정보 사용자가 입력한 Twelve Data API 키 Twelve Data API 인증
체결 알림 자동 가져오기 사용자가 알림 접근을 허용한 경우 카카오톡 알림의 제목·본문, 알림 시각, 종목·체결일·매매구분·가격·수량·정산금액 체결정보 추출과 사용자 승인 대기
체결 알림 제외 설정 사용자가 선택한 종목코드·종목명·증권사·계좌 끝 2자리 조합 해당 조합의 향후 체결 알림 수집 제외
백업 위치 사용자가 선택한 Google Drive 폴더의 접근 URI와 표시 이름 이후 암호화 백업·복원 시 선택 폴더 이용

2. 보관 위치와 기간

  • 운용자료와 앱 설정은 사용자의 앱 전용 저장소에 보관하며, 사용자가 자료를 삭제하거나 앱 데이터 또는 앱을 제거할 때까지 보관합니다.
  • 승인 대기 체결 알림은 승인하거나 삭제할 때까지 기기에 보관합니다. 최대 100건을 초과하면 오래된 항목부터 자동 삭제합니다.
  • 체결 알림 제외 설정은 기기 내부에 보관하며, 전체메뉴 → 체결 알림 자동 가져오기 → 체결 알림 제외 관리에서 해당 항목의 ‘다시 가져오기’를 켜거나 앱 데이터 삭제·앱 제거 시 삭제됩니다. 운용카드 삭제만으로는 제외 설정이 삭제되지 않습니다.
  • Twelve Data API 키는 Android Keystore의 키를 이용한 AES-GCM 방식으로 암호화해 기기에 저장하며, 사용자가 삭제할 때까지 보관합니다.
  • Google Drive 백업 파일은 사용자가 선택한 Drive 폴더에 사용자가 삭제할 때까지 보관됩니다.
  • 앱의 Android 자동 백업과 기기 간 자동 전송은 비활성화되어 있습니다.

3. 외부 서비스 전송

StarTrade(스타매매)는 운용자료나 체결 알림, 체결 알림 제외 설정을 개발자 서버로 자동 전송하지 않습니다. 다음 기능을 사용할 때만 해당 서비스와 직접 통신합니다.

받는 서비스전송 항목목적·시점보관
Yahoo Finance 조회할 종목코드 또는 통화쌍·조회 기간과 IP 주소 등 통신정보 사용자가 새로고침을 실행하거나 주문계획 화면 진입, 거래 변경·복원 후 환율 보완 등 앱의 자동 갱신 조건이 충족될 때 종가·환율 조회 Yahoo 정책에 따름
Twelve Data 조회할 종목코드 또는 통화쌍·조회 기간, API 키와 IP 주소 등 통신정보 Twelve Data를 사용하는 경우, 사용자가 새로고침을 실행하거나 주문계획 화면 진입, 거래 변경·복원 후 환율 보완 등 앱의 자동 갱신 조건이 충족될 때 종가·환율 조회·인증 Twelve Data 정책에 따름
Google Drive 비밀번호로 암호화된 운용 백업 파일 사용자가 Google Drive 백업을 직접 실행할 때 사용자의 Drive에서 직접 삭제할 때까지
  • Yahoo 이용조건
  • Twelve Data 이용조건
  • Google 개인정보처리방침

4. 백업과 암호화

  • 새 백업 파일은 사용자가 지정한 8자 이상의 비밀번호에서 생성한 키와 AES-256-GCM을 사용해 암호화합니다.
  • 백업 비밀번호는 앱에 저장하지 않으며 분실 시 복구할 수 없습니다.
  • Twelve Data API 키, 승인 대기 체결 알림과 체결 알림 제외 설정은 백업 파일에 포함하지 않습니다.
  • 휴대전화 저장소나 Google Drive에 저장된 백업 파일의 보관과 삭제는 사용자가 관리합니다.

5. 알림 접근 선택권

  • 체결 알림 자동 가져오기는 기본적으로 꺼져 있으며, 사용자가 앱의 안내를 확인하고 Android 설정에서 알림 접근을 허용한 경우에만 작동합니다.
  • 앱은 카카오톡 체결 후보 알림만 분석하고 다른 앱 알림은 승인 대기함에 저장하지 않습니다.
  • 사용자는 전체 메뉴의 ‘체결 알림 자동 가져오기’와 Android 알림 접근 설정에서 언제든 기능을 끌 수 있습니다.

6. 사용자의 권리와 삭제 방법

사용자는 앱에서 다음 작업을 직접 수행할 수 있습니다.

  • 운용카드와 매매기록 삭제
  • 승인 대기 체결 알림 승인 또는 삭제
  • 전체메뉴 → 체결 알림 자동 가져오기에서 종목·증권사·계좌별 제외 설정 해제
  • Twelve Data API 키 삭제
  • Google Drive 또는 휴대전화에 저장한 백업 파일 삭제
  • 앱 설정에서 알림 접근 권한 철회
  • Android 앱 정보에서 앱 데이터 전체 삭제 또는 앱 제거

개인정보 처리와 삭제 방법에 관한 문의는 lowsky.lab@gmail.com으로 접수할 수 있습니다. 개발자는 사용자의 기기나 Google Drive에 저장된 자료에 접근하거나 이를 원격으로 삭제할 수 없습니다. 자료 삭제는 위 방법에 따라 사용자가 직접 수행해야 합니다.

7. 아동의 개인정보

StarTrade(스타매매)는 아동을 대상으로 하지 않으며 나이를 수집하지 않습니다.
