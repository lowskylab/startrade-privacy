2. 보관 위치와 기간

  • 운용자료와 앱 설정은 사용자의 앱 전용 저장소에 보관하며, 사용자가 자료를 삭제하거나 앱 데이터 또는 앱을 제거할 때까지 보관합니다.
  • 업데이트 후 기존 카드별 증권사 앱·계좌 끝 2자리를 기기 내부의 증권사 연결 목록에 자동 등록합니다. 같은 앱·계좌는 묶고 기본 증권사와 각 카드의 연결을 유지합니다. 이전 전 카드 설정은 앱 내부에 한 번 보관하며(API 키 제외), 앱 데이터 삭제·앱 제거 시 삭제됩니다. 이전 자체는 외부 전송이나 API 활성화를 수행하지 않습니다.
  • 승인 대기 체결 알림은 승인하거나 삭제할 때까지 기기에 보관합니다. 최대 100건을 초과하면 오래된 항목부터 자동 삭제합니다.
  • API 체결정보는 승인 대기에 보관하고 사용자 승인 후 매매이력에 기록합니다. 승인한 기록은 일반 운용자료와 같은 기간 보관합니다. 자율형 주문과 사용자 확인 없는 체결 자동 기록은 제공하지 않습니다.
  • 체결입력에서 카카오톡 또는 API 체결정보를 선택합니다. API 경로를 선택한 카드는 카카오톡 체결 자동 연결에서 제외합니다. API가 활성화되고 연결 점검이 완료된 운용은 앱 시작/복귀·API 경로 전환 시와 앱이 닫힌 동안의 약 15분 주기 작업에서도 조회합니다. 절전·통신·강제종료 상태에 따라 지연/누락될 수 있습니다. API OFF·카카오톡 전환·운용 종료·미검증 연결은 대상에서 제외하며 대상이 없으면 예약을 취소합니다. 자동 조회 상태는 앱 데이터 삭제·앱 제거 시 삭제합니다. 감독형 알림은 사용자 확인을 요청할 뿐 API 조회·주문을 실행하지 않습니다.
  • VR 기간잔량 예약의 시작일·종료일과 예약번호는 메리츠에 전송하고 기기에 기록합니다. API OFF·앱 종료·앱 삭제는 증권사에 접수된 예약을 취소하지 않습니다. 예약 취소와 이미 발주된 실제 주문 취소는 별도입니다. 예약번호와 실제 주문번호의 연결을 확인하지 못한 체결은 사용자 승인 대상으로 남깁니다.
  • Twelve Data API 키는 Android Keystore의 키를 이용한 AES-GCM 방식으로 암호화해 기기에 저장하며, 사용자가 삭제할 때까지 보관합니다.
  • 증권사 API 인증정보도 별도의 Android Keystore 키와 AES-GCM으로 암호화해 기기에 저장합니다. 전체메뉴 > 증권사 연결 > 연결 설정에서 삭제하거나 앱 데이터 삭제·앱 제거 시 삭제할 수 있습니다.
  • Google Drive 백업 파일은 사용자가 선택한 Drive 폴더에 사용자가 삭제할 때까지 보관됩니다.
  • 앱의 Android 자동 백업과 기기 간 자동 전송은 비활성화되어 있습니다.

4. 백업과 암호화

  • 새 백업 파일은 사용자가 지정한 8자 이상의 비밀번호에서 생성한 키와 AES-256-GCM을 사용해 암호화합니다.
  • 백업 비밀번호는 앱에 저장하지 않으며 분실 시 복구할 수 없습니다.
  • Twelve Data API 키, 승인 대기 체결 알림과 체결 알림 제외 설정은 백업 파일에 포함하지 않습니다.
  • 증권사 API 인증정보와 연결 등록 목록도 백업 파일에 포함하지 않습니다. 운용에 선택된 연결 ID·앱·계좌 끝자리 설정은 운용자료로 포함됩니다. 복원된 카드에 앱·계좌 정보가 있으면 빠진 연결을 다시 구성합니다. 복원 후 계좌 연결을 확인하고 API 인증정보는 다시 등록해야 합니다.
  • API 주문 원장·예약 설정·점검 정보 및 자동 조회 시각·상태는 기기에만 저장하고 백업에서 제외합니다. 사용자 승인으로 매매이력에 저장한 API 체결과 식별 키는 운용자료에 포함합니다. 주문 원장은 중복 방지를 위해 운용 삭제 후에도 남으며 앱 데이터 삭제·앱 제거 시 삭제됩니다.
  • 백업 복원 시 모든 API 운용 설정을 OFF로 전환합니다. API OFF·앱 종료는 증권사에 접수된 주문을 취소하지 않습니다.
  • 휴대폰 저장소나 Google Drive에 저장된 백업 파일의 보관과 삭제는 사용자가 관리합니다.

5. 카카오톡 알림 접근과 API 조회 선택권

  • 카카오톡 체결 알림 자동 가져오기는 기본적으로 꺼져 있으며, 사용자가 앱의 안내를 확인하고 Android 설정에서 알림 접근을 허용한 경우에만 작동합니다.
  • 앱은 카카오톡 체결 후보 알림만 분석하고 다른 앱 알림은 승인 대기함에 저장하지 않습니다.
  • 사용자는 전체 메뉴의 체결 알림 자동 가져오기와 Android 알림 접근 설정에서 언제든 기능을 끌 수 있습니다.

API 체결 조회는 카카오톡 알림 접근 권한을 사용하지 않습니다. API 사용과 체결 경로를 직접 선택하며 API OFF 또는 카카오톡 전환으로 자동 조회를 중단할 수 있습니다. 알림 표시 권한은 새 승인 대기 체결을 알려주기 위한 것으로 조회·주문 자동 승인을 허용하는 권한이 아닙니다. 네트워크 상태 확인 권한은 통신 가능한 때에 시스템 예약 조회를 수행하기 위해 사용합니다. 이 작업은 포그라운드 서비스를 사용하지 않습니다.

6. 사용자의 권리와 삭제 방법

사용자는 앱에서 다음 작업을 직접 수행할 수 있습니다.

  • 운용카드와 매매기록 삭제
  • 승인 대기 체결 알림 승인 또는 삭제
  • Twelve Data API 키 삭제
  • Google Drive 또는 휴대폰에 저장한 백업 파일 삭제
  • 앱 설정에서 알림 접근 권한 철회
  • API 인증정보 삭제·운용 API OFF, 감독형 알람 및 알림 권한 철회
  • 안전설정을 켠 뒤 미사용 증권사 연결 삭제. 연결 삭제 시 인증정보를 제거하며 사용 중인 카드·API 주문 이력 연결은 삭제를 제한합니다.
  • 전체메뉴 → 체결 알림 자동 가져오기에서 종목·증권사·계좌별 제외 설정 해제
  • Android 앱 정보에서 앱 데이터 전체 삭제 또는 앱 제거

개인정보 처리와 삭제 방법에 관한 문의는 lowsky.lab@gmail.com으로 접수할 수 있습니다. 개발자는 사용자의 기기나 Google Drive에 저장된 자료에 접근하거나 이를 원격으로 삭제할 수 없습니다. 자료 삭제는 위 방법에 따라 사용자가 직접 수행해야 합니다.

7. 아동의 개인정보

스타매매는 아동을 대상으로 하지 않으며 나이를 수집하지 않습니다.

8. 처리방침 변경

기능, 외부 서비스 또는 관련 법령이 변경되면 이 처리방침을 수정하고 시행일을 갱신합니다. 중요한 변경은 Google Play 앱 설명 또는 앱 내부 고지를 통해 안내합니다.

체결 알림 제외 설정

사용자가 선택한 종목 코드/이름·증권사·계좌 끝 2자리 조합은 향후 체결 알림 수집 제외를 위해 기기 내부에 보관합니다. 전체메뉴 > 체결 알림 자동 가져오기에서 다시 가져오기를 켜면 해당 제외 설정이 삭제됩니다. 제외 설정은 운용카드를 삭제해도 유지하며, 해당 항목의 다시 가져오기·앱 데이터 삭제·앱 제거 시 삭제됩니다. 백업에 포함하지 않으며 외부로 전송하지 않습니다.
